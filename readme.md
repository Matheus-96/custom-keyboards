# Quantum Mechanical Keyboard Firmware

O **QMK** é um firmware open source super popular para teclados mecânicos customizados, permitindo personalizar cada tecla, criar macros e muito mais. Já o **Vial** é uma interface gráfica que facilita ainda mais a configuração do teclado, permitindo mudanças rápidas e intuitivas sem precisar compilar ou regravar o firmware toda hora.
